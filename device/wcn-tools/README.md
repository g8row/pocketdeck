# WMT userspace (wmt_loader, stp_uart_launcher)

From BPI-SINOVOIP/BPI-R2-bsp-4.14 `linux-mt/utils/wmt/src` (master), MediaTek's combo_tool built for plain Linux
with `STATIC_BUILD`. The sources carry no license header and the repository has no license file.
Built static for aarch64 in the tb7304-build container: `make CC=aarch64-linux-gnu-gcc`.
Usage: docs/mainline/research-wifi.md, "Bring-up".
